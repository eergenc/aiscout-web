# aiscout.tr

AI Scout Türkiye web sitesi. Saf HTML/CSS/JS, derleme adımı yok, tüm dosyalar tek klasörde.

- `index.html` — Türkçe ana sayfa (aiscout.tr)
- `en.html` — İngilizce sürüm (aiscout.tr/en)
- `kvkk.html` — KVKK aydınlatma metni (TASLAK: sarı alanları doldur, hukukçuya kontrol ettir)
- `styles.css`, `site.js` — stil ve script
- Görseller: logo, seri logoları, ikonlar, og-image

İletişim formu Web3Forms ile info@aiscout.tr'ye gönderir.

Yayın: Cloudflare Pages → Framework: None, Build command: boş, Output directory: boş.
